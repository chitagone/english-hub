# English Hub ✿✎

Speaking + dictation practice apps, built from my own English books
(Master Vocab · Conversation Pattern Books · Grammar & Sentence Patterns).

- **WriteRight ✎** — listen & write dictation: words, sentences, or paste your
  own article. Type it (auto-check with letter diff) or write it in your book
  and reveal. Voice picker, Apple Pencil support, A–Z letter filter.
- **SpeakEasy ✿** — question & answer speaking card game + grammar quiz with
  spaced review.

No server, no build step — plain HTML/CSS/JS. Progress and themes are saved in
your browser.

Deployed on GitHub Pages.
