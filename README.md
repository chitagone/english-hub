# English Hub ✿✎

Speaking + dictation practice apps, built from my own English books
(Master Vocab · Conversation Pattern Books · Grammar & Sentence Patterns).

- **WriteRight ✎** — listen & write dictation: words, sentences, meanings (hear the
  meaning → write the word), or paste your own article. Type it (auto-check with
  letter diff) or write it in your book and reveal. Voice picker, Apple Pencil
  support, A–Z letter filter.
- **SpeakEasy ✿** — speaking practice: answer/ask flashcards with record &
  compare, **roleplay mode** (full conversations turn by turn), **shadowing**
  (hear a phrase, repeat it), **1-minute talks** (random topic + timer +
  recording), and a grammar quiz — all with spaced review and streaks.

No server, no build step — plain HTML/CSS/JS. Progress and themes are saved in
your browser.

Deployed on GitHub Pages.
